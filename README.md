# 桌面番茄钟

一个基于 Python 标准库 `tkinter` 构建的离线桌面番茄钟。无需安装第三方依赖，支持专注/休息自动循环、时长方案自定义、完成提醒、快捷键和配置持久化。

## 功能特性

- 经典番茄工作法：专注、短休息、长休息自动切换。
- 独立时长自定义模块：内置经典番茄、短时专注、深度工作、轻量循环四套预设，也支持完全自定义。
- 界面风格自定义：国风、商务、儿童、仙女、清爽五套主题，选择后即时预览，点击应用后保存。
- 精致界面布局：渐变标题卡、独立统计卡片、增强进度环和更清晰的按钮层级。
- v0.2.0 任务计划：添加任务、估算番茄数、设置当前任务，专注完成后自动累加进度。
- v0.2.0 专注数据：累计番茄、近 7 天趋势、连续打卡和成就展示。
- v0.2.0 休息奖励：随机转盘决定休息方式。
- 完成提醒：桌面弹窗、系统提示音、主窗口抖动；窗口最小化时会自动恢复并临时置顶。
- 控制方式：开始、暂停、继续、重置、跳过。
- 快捷键：空格开始/暂停，`R` 重置，`S` 跳过。
- 设置持久化：界面风格、时长方案、提示音、自动开始下一阶段、窗口置顶和当前任务会自动保存。
- 无第三方依赖：仅使用 Python 标准库。

## 环境要求

- Python 3.10 及以上版本
- Python 安装需包含 `tkinter`（Windows 安装时勾选 `tcl/tk and IDLE`）
- Windows、macOS 或 Linux 桌面环境

## 快速开始

### Windows 双击启动

双击项目目录中的 `启动番茄钟.bat`。

脚本会优先使用无控制台的 `pyw` / `pythonw` 启动程序，启动后 bat 窗口会自动关闭。若未找到可用 Python，窗口会显示错误提示。

### 命令行启动

```powershell
python main.py
```

如果系统中有多个 Python 版本：

```powershell
py -3 main.py
```

## 使用说明

- 在 `当前任务` 输入框中填写本次专注目标，内容会自动保存。
- 点击 `开始专注` 开始计时，再次点击可暂停或继续。
- 点击 `时长自定义` 打开独立窗口，选择预设方案或填写自定义时长。
- 点击 `任务计划` 添加任务、设置估算番茄数，并指定当前任务。
- 点击 `专注数据` 查看统计趋势和已解锁成就。
- 点击 `休息奖励` 打开随机奖励转盘。
- 点击 `设置` 可调整界面风格、自动开始下一阶段、提示音和窗口置顶。
- 阶段自然结束时会计入完成次数；点击 `跳过` 不计入完成次数。
- 更完整的中文说明见 [`使用说明.md`](使用说明.md)。

## 时长预设

| 方案 | 专注 | 短休息 | 长休息 | 长休息轮次 |
| --- | ---: | ---: | ---: | ---: |
| 经典番茄 | 25 分钟 | 5 分钟 | 15 分钟 | 4 轮 |
| 短时专注 | 15 分钟 | 3 分钟 | 10 分钟 | 4 轮 |
| 深度工作 | 50 分钟 | 10 分钟 | 20 分钟 | 4 轮 |
| 轻量循环 | 10 分钟 | 2 分钟 | 8 分钟 | 6 轮 |

自定义范围：专注 1-180 分钟，短休息 1-60 分钟，长休息 1-90 分钟，长休息轮次 2-12 轮。

## 界面风格

在 `设置` 面板的 `界面风格` 下拉框中选择主题会立即预览效果；确认满意后点击 `应用设置` 保存：

| 主题 | 风格 |
| --- | --- |
| 国风 | 宣纸底色、朱砂点缀、青玉辅助，搭配楷体气质 |
| 商务 | 深蓝背景与高对比强调色，沉稳专注（默认） |
| 儿童 | 明亮活泼的糖果色 |
| 仙女 | 柔和粉紫与浅蓝 |
| 清爽 | 浅青与白色，简洁明快 |

主题会同步应用到主窗口和时长自定义弹窗，并在重启后保留。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| 空格 | 开始 / 暂停 / 继续 |
| `R` | 重置当前阶段 |
| `S` | 跳过当前阶段 |
| `Esc` | 在时长自定义窗口中取消 |

输入框或数字微调框获得焦点时，主界面快捷键不会触发。

## 数据保存位置

设置、任务和统计数据保存在用户主目录：

```text
~/.focus_pomodoro/settings.json
~/.focus_pomodoro/tasks.json
~/.focus_pomodoro/stats.json
```

Windows 中目录为：

```text
%USERPROFILE%\.focus_pomodoro\
```

删除对应文件即可分别恢复默认设置、清空任务或清空统计数据。
